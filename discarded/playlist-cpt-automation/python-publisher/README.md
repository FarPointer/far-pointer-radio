# Discarded Python Publisher

Historical packaged REST publisher for the abandoned WordPress `playlist`
custom post type. Do not install or run it.

| File | Contents |
|---|---|
| `cli.py` | Click commands |
| `wordpress.py` | REST client |
| `render.py` | Gutenberg block rendering |
| `config.py`, `paths.py` | Configuration and paths |
| `pyproject.toml`, `uv.lock` | Package and dependency metadata |
| `original-readme.md` | Original usage and design notes |

The replacement will be a narrow Bash/`jq` publisher for ordinary WordPress
posts.
