# Docs

Project-wide documentation for the far-pointer-radio repository.

| File | Contents |
|---|---|
| `operating-procedures.md` | The short version of each recurring workflow — weekly cache refresh, override review, publishing, archiving, ending a session |

Show-specific documentation lives under `shows/<show>/docs/`. Working conventions are in
`CONTRIBUTING.md`; agent guidance is in `AGENTS.md`.

Decision records belong here when they are repository-wide and under `shows/<show>/docs/`
when they are not. Name them for what they decide, not for the date.
