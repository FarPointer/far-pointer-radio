# Convergence Zone

[Convergence Zone](https://convergencezone.fm) is an independent radio program.

## Directory Structure

| Directory | Contents |
|---|---|
| `playlists/` | Episode playlists — Spinitron exports, CSV, and hand-edited files |
| `website/` | WordPress theme overrides, custom CSS, copy, and assets |
| `images/` | General show images (logos, banners, photos) |
| `docs/` | Show notes, rundowns, standard operating procedures |
| `docs/press-kit/` | One sheets, bios, and other press materials |
| `docs/press-kit/images/` | Images used in press kit materials |

## Playlist Format

Playlists exported from Spinitron are saved as CSV.  
File naming convention: `YYYY-MM-DD-episode-title.csv`
