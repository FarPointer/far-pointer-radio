# Playlists

Episode playlists for Convergence Zone.

## Directory Structure

| Directory | Contents |
|---|---|
| `sources/` | Raw, unedited playlist material as it came out of each upstream system |
| `analysis/` | Working files from reconciling `sources/` against what Spinitron logged |
| `cache/` | The canonical datastore of broadcasts and spins, generated by `czcache` — see `schema.ts` |
| `docs/` | Documentation specific to playlist operations and reference data |
| `publication-links.json` | WordPress post identity/URL and optional Mixcloud URL, keyed by broadcast date; consumed by `czcache` |

## Playlist Format

Playlists exported from Spinitron are saved as CSV.
File naming convention: `YYYY-MM-DD-episode-title.csv`

Files under `sources/` are exempt from that convention — they keep the names their
originating system gave them so they can be traced back to the export they came from.
