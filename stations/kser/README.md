# KSER

Projects related to [KSER 90.7 FM](https://www.kser.org) and its non-profit group.

## Project Areas

| Directory | Purpose |
|---|---|
| `website/` | Website assets, copy, and updates |
| `volunteering/` | Volunteer schedules, contacts, and coordination |
| `logistics/` | Operational notes, runbooks, and logistics |
| `board/` | Board work, meeting notes, and governance documents |
| `job-applications/` | Application materials for station positions |
| `docs/` | General documentation and correspondence |
